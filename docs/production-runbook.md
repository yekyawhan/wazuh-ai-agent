# Production Runbook

## Startup Checklist

- Verify Docker Swarm health
- Verify integrations
- Check Wazuh manager status
- Check AI agent services
- Validate n8n workflows

## Incident Handling

1. Alert received
2. AI analysis performed
3. Threat intelligence enrichment
4. Case creation
5. Response execution
6. Post incident review

## Recovery

- Restore service state
- Validate data persistence
- Review logs
- Confirm monitoring status
